# Implantes Dentales Barcelona

Web de Implantes Dentales Barcelona con el Dr. Diego Uribe Echevarría.

React + Vite + Tailwind CSS v4 + Motion. Disponible en español, catalán, inglés y alemán.

## Desarrollo

```bash
npm install
npm run dev
```

## Publicación

```bash
npm run build
```

Genera la web estática en `dist/`.

## Dónde está cada cosa

- `src/content/<idioma>.js`: textos de cada idioma (es, ca, en, de)
- `src/data.js`: teléfonos, dirección, clínicas y enlaces, que son iguales en todos los idiomas
- `public/img`: imágenes
- Los puntos pendientes de confirmar con el cliente están marcados con `REVISAR` en el código.
